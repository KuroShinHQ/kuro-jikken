# data/recipes

Gated procedure documents (`kj-recipe/1`). Read `docs/PROCEDURE.md` first.

- Text is authored for this repository; facts are attributed per source in the
  `sources` array, with the licence note recorded next to each URL.
- `design` means "this is a choice of the recipe", not a measured fact.
- `python mcp/recipe.py <file>` validates; `python tools/recipe_page.py --all`
  renders the three.js page from the same JSON, and `--check` fails on drift.
- Nothing here is medical advice. A procedure may be useful and still be
  explicitly unable to treat, cure or prevent a disease.
