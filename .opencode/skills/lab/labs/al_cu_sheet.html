How it is computed

  • x(Cu) from wt%: nCu = w/63.546, nAl = (100−w)/26.9815, x = nCu/(nCu+nAl)
  • liquidus: bisect T where any solid phase has NP > 1e−6 (9 steps), bracket reported
  • xCu = 0: no bracket exists, pure-element path (FCC_A1 → LIQUID)

    Reading the sheet

    The number on top is not a fit. It is the temperature at which pycalphad finds the last solid fraction disappearing in the MatCalc Al-Cu database, bisected at that composition and stored as one ledger entry. Each row below is the same procedure at another composition; the curve is drawn through those rows, not through a formula.

    The page behind this sheet snaps to the same 21 points. Between them the page model interpolates linearly inside a declared ±0.5 K, and lab_audit.py checks every midpoint against the engine: worst case measured 0.3418 K.

    Why this is not a simulation

    The database is an assessment of published Al–Cu thermodynamics (mc_al_v2.032). The ±0.342 K is the bisection bracket — how tightly the solver closed in — not the uncertainty of the database. A real measurement of this liquidus would carry its own error, usually several kelvin, and that error is not claimed here.
